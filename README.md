# 🧩 Maze Path Finder

A Maze Path Finder project that visualizes and computes the shortest path from a start point to a goal within a maze using intelligent pathfinding techniques.

---

## 🚀 Features

- 📌 Maze representation using grid-based structure
- 🔍 Intelligent pathfinding (shortest path detection)
- ⬆️⬇️⬅️➡️ Supports movement in four directions
- 🧠 Efficient node exploration and backtracking
- ❌ Handles unreachable goals gracefully
- 📊 Displays visited paths and final solution

---

## 🛠️ Technologies Used

- JavaScript (Core Logic)
- HTML (Structure)
- CSS (Styling)

## ⚙️ How It Works

1. The maze is loaded into the system.
2. The algorithm explores possible paths (up, down, left, right).
3. It selects the most optimal node towards the goal.
4. Continues until:
   - ✅ Goal is reached → shortest path is displayed
   - ❌ Goal is unreachable → visited nodes are marked
